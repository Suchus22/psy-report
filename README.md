# MYLIFE MEDICAL CENTER — ระบบบันทึกการประเมินสภาพจิตใจ (ใช้งานร่วมกับ Google Sheets)

เว็บแอพไฟล์เดียว `index.html` + หลังบ้าน `Code.gs` เก็บข้อมูลลง Google Sheets

## 1. ไฟล์ในโฟลเดอร์นี้
- `index.html` — หน้าเว็บหลัก (เปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง)
- `Code.gs` — โค้ดฝั่ง Google Apps Script (ต้องเอาไปวางใน Google Sheet)
- `Pictures/001.png` — โลโก้โรงพยาบาล (ต้องอยู่ข้างๆ index.html โฟลเดอร์ Pictures ห้ามย้าย)

## 2. ติดตั้งครั้งแรก (ทำครั้งเดียว 5 นาที)

### 2.1 สร้าง Google Sheet
1. เปิด https://sheets.new (ล็อกอิน Gmail ของ รพ.)
2. ตั้งชื่อไฟล์ เช่น `PsyAssessmentDB`
3. ไม่ต้องสร้างคอลัมน์เอง โค้ดจะสร้างแท็บ `Assessments` + หัวคอลัมน์ให้อัตโนมัติ:
`id | timestamp | name | position | emotion_control | empathy | dilemma | notes | diagnosis | recommendation | psychiatrist | assess_date`

### 2.2 วางโค้ด Apps Script
1. ในชีต เมนู **ส่วนขยาย → Apps Script** (Extensions → Apps Script)
2. ลบโค้ดตัวอย่างเดิมทิ้งทั้งหมด
3. เปิดไฟล์ `Code.gs` ในโฟลเดอร์นี้ copy ทั้งไฟล์ไปวางแทน แล้วกด **Save (Ctrl+S)**

### 2.3 Deploy เป็น Web App
1. ใน Apps Script กด **Deploy → New deployment**
2. รูปเฟือง → เลือก **Web app**
3. กรอก:
   - Description: `psy-api`
   - Execute as: **Me** (อีเมลของ รพ.)
   - Who has access: **Anyone** (สำคัญ ไม่งั้นหน้าเว็บยิงข้อมูลไม่ได้)
4. กด **Deploy → Authorize access → เลือกบัญชี → Advanced → Go to project → Allow**
5. Copy **Web App URL** (ขึ้นต้น https://script.google.com/macros/s/AKf...) เก็บไว้

### 2.4 เอา URL มาใส่ในเว็บ
1. ดับเบิลคลิกเปิด `index.html`
2. ไปแท็บ **ตั้งค่า**
3. วาง Web App URL → กด **บันทึก** → กด **ทดสอบ**
   - ขึ้น `เชื่อมต่อสำเร็จ` = ใช้ได้
   - ขึ้น `เชื่อมต่อไม่สำเร็จ` = ดูหัวข้อแก้ปัญหา

### 2.5 ทดสอบบันทึกจริง
1. ไปแท็บแบบฟอร์ม กรอกชื่อทดสอบ 1 ราย → กดบันทึก → กด OK ยืนยัน
2. กลับไปดู Google Sheet แท็บ `Assessments` ต้องมีแถวใหม่เพิ่ม
3. ในเว็บแท็บประวัติ กด **ดึงจาก Google Sheets** ต้องเห็นรายการเดียวกัน

## 3. ใช้งานประจำวัน
- **บันทึก:** กรอกฟอร์ม → กดบันทึก → ยืนยัน OK → ฟอร์มล้างพร้อมรายใหม่ทันที
- **ค้นด่วน:** ช่องชื่อ / ชื่อแพทย์ / บันทึกเพิ่มเติม / ข้อแนะนำ พิมพ์ 1-2 ตัวอักษรจะมีดรอปดาวน์ประวัติเดิมให้คลิก เลือกชื่อคนไข้จะดึงอาชีพเดิมมาให้อัตโนมัติ
- **ประวัติ:** ช่องค้นหาค้นได้ทุกคอลัมน์ (ชื่อ วันที่ อาชีพ บันทึก ข้อแนะนำ แพทย์) + กรองตามผลวินิจฉัย
- **พิมพ์รายคน:** กดปุ่มพิมพ์ในแถว (แนวตั้ง)
- **พิมพ์ตามที่ค้น:** ค้น/กรองก่อน แล้วกด **พิมพ์รายงานตามที่ค้น** (แนวนอน A4 ตารางรวม ถ้าพอหน้าเดียวจะออกหน้าเดียว)
- **Export:** ปุ่ม Export CSV สำรองข้อมูลได้

## 4. นำไปใช้ใหม่อีกครั้ง (เครื่องใหม่ / ชีตใหม่)
- **ใช้ชีตเดิมกับเครื่องใหม่:** แค่ copy `index.html` + โฟลเดอร์ `Pictures` ไปเครื่องใหม่ เปิดเว็บ → แท็บตั้งค่า → วาง Web App URL เดิม → บันทึก → กดดึงจาก Google Sheets
- **ขึ้นชีตใหม่ (ปีใหม่/หน่วยใหม่):** สร้างชีตใหม่ → ทำข้อ 2.2-2.4 ใหม่ จะได้ URL ใหม่ → เอามาวางแทน URL เดิม
- **แก้ Code.gs ภายหลัง:** แก้ใน Apps Script → กด **Deploy → Manage deployments → Edit → New version** ทุกครั้ง ไม่งั้นเว็บยังเรียกตัวเก่า
- **ล้างเครื่อง:** แท็บตั้งค่า → ปุ่มลบข้อมูลในเครื่อง (ข้อมูลใน Sheets ไม่หาย)

## 5. แก้ปัญหาเบื้องต้น
| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| ทดสอบเชื่อมต่อไม่ผ่าน | URL ผิด / Deploy เป็น Anyone หรือยัง / ลองเปิด URL + `?action=ping` ในเบราว์เซอร์ต้องขึ้น pong |
| บันทึกแล้วข้อมูลไม่เข้าชีต | ยังไม่วาง URL / Deploy เก่า / สิทธิ์ชีต / ดู Executions ใน Apps Script ว่ามี error ไหม |
| กดดึงจาก Sheets แล้วว่าง | ชีตยังไม่มีแท็บ Assessments / header แถวแรกไม่ตรง 12 คอลัมน์ / มีแถวว่างคั่น |
| วันที่ค้นไม่เจอ | พิมพ์รูปแบบ YYYY-MM-DD เช่น 2026-10-15 |
| โลโก้ไม่ขึ้น/พิมพ์ไม่มีโลโก้ | ไฟล์ `Pictures/001.png` ไม่อยู่ข้าง index.html / เปิดเว็บผ่าน file:// ต้องคงโครงโฟลเดอร์เดิม |
| พิมพ์ออก 2 หน้า (หน้าว่าง) | ตั้งค่าพิมพ์ Margins: Default, ไม่ติ๊ก Headers/Footers, ตารางสรุปใช้ Landscape, ใบรายคนใช้ Portrait |

## 6. ความปลอดภัย
- URL ลงท้าย `/exec` เปรียบเหมือนรหัสผ่าน อย่าแชร์สาธารณะ ส่งให้เฉพาะเครื่องที่ใช้
- ชีตแชร์เฉพาะแพทย์ที่เกี่ยวข้อง (Viewer/Editor) ไม่ต้องแชร์ Anyone
- ควร Export CSV สำรองทุกสัปดาห์ (แท็บประวัติ → Export CSV)
